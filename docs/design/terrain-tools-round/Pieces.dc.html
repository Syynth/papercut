Ramps and pieces: four ways in, one way out

WayWhat it does
Ramp, from an edgeAs today: drag back from a cliff edge and the run is cut, with a half ramp to finish an odd drop. Kept because it is the quickest way to get down a cliff.today
Ramp, between two heightsPress on the high ground, release on the low: the straight run between them becomes a slope, as wide as the brush. Where the run is too short for 45° it says so, as the edge drag does.new
Piece, by handBuild › Block with the Piece picker: one slab, one ramp, one half ramp, anywhere, facing the way you drag.new
ReshapeSculpt › Ramp pressed on a level top, with no edge in reach, turns that top into the picked piece: a cube into a slab, a slab into a ramp. The way to fix one cell without rebuilding it.new
OutShift with any of them puts the cube back. Raise, Flatten and Extrude on a ramp treat it as the cube it stands in, and leave a cube.changed

Stairs are ramps — tentative since 2026-09-19

A staircase is a ramp whose art draws steps, so nothing here is special for stairs: the same runs, the same pieces, the same rails. Build › Stairs is only the shape fill that lays a run of ramps in free air, with the body under it, for stairs that do not start from a cliff.
